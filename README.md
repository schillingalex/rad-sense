# Overview

NOS3 component for a radiation detector and simulated radiation events

# Installation in NOS3

Add component as git submodule:

```bash
git submodule add -b main https://github.com/schillingalex/rad-sense.git components/rad_sense
```

# Run tests

To run tests, use the tests target of make:

```bash
make tests
```

Success of the make command means all tests succeeded.
